# LEONTIEVA — продюсерский центр

Официальный сайт продюсерского центра Елены Леонтьевой.

Основной адрес: [leontieva.media](https://leontieva.media)

## Текущее предложение

- участие эксперта на ТВ с подтверждением согласованного выхода;
- видеоинтервью с публикацией и ссылкой на выпуск;
- дополнения к выбранной базе и другие форматы;
- стратегия и GR — отдельно, по запросу.

Стоимость — по запросу: после выбора площадки. До заказа согласуются полный состав, цена и условия по срокам. Елена ведёт заказ. Необходимая подготовка и координация входят в базу; уже включённое повторно не оплачивается. Передача видеофайла и права использования определяются отдельно для выбранной площадки.

Примеры из каталога не обозначают автоматически работы команды. Закупочные цены и контакты подрядчиков не публикуются.

## Разработка

Основная публикация работает как статический сайт через GitHub Pages. Актуальная клиентская версия — `index.html`, `interview/index.html`, `strategy/index.html`, `support/index.html`, `styles.css` и `lead-form.js`. Изображения и `CNAME` лежат в корне проекта. Перенос изменений в эту папку сам по себе не публикует сайт.

Для просмотра именно статических страниц из корня проекта:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8080/`. PDF для кнопок сайта:

- `assets/leontieva-media-formats.pdf` — форматы и примеры;
- `assets/leontieva-media-services.pdf` — услуги и стоимость.

Исходная версия на vinext в `app/` сохранена как прежняя версия для разработки. `npm run dev` запускает её, а не текущие статические страницы. Она не является источником новой клиентской формулировки. Команда `npm test` проверяет её сборку и маршруты, а также текущие статические страницы и подготовку письма.

Систему публикации, домен и перенаправления не менять при редактировании содержания.

Контакты Елены: `pr@leontieva-media.ru`, `+7 968 910-33-19`. Форма открывает письмо через `mailto`; посетитель отправляет его из своей почтовой программы. Сайт не хранит и не отправляет заявку. События `leontieva:contact-intent` обозначают открытие письма или нажатие почтовой ссылки, а не доставку сообщения.
